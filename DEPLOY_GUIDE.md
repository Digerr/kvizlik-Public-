# КВИЗЛИК — Полное руководство по запуску
# Для Android телефона (без компьютера)

=============================================
ШАГ 1: СОЗДАЙ TELEGRAM БОТА
=============================================

1. Открой Telegram
2. Найди @BotFather (с синей галочкой ✓)
3. Отправь: /newbot
4. Придумай имя бота: КВИЗЛИК
5. Придумай username: kvizlik_bot (или любой свободный, должен заканчиваться на _bot)
6. BotFather пришлёт тебе ТОКЕН — длинную строку вида:
   7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxx
7. СКОПИРУЙ ЭТОТ ТОКЕН! Он нужен будет дальше.

💡 Сохрани токен куда-нибудь (Заметки, Keep и т.д.)

=============================================
ШАГ 2: ЗАГРУЗИ КОД НА GITHUB
=============================================

ВАРИАНТ А — Через браузер (проще всего):

1. Открой https://github.com в браузере телефона
2. Зарегистрируйся / войди
3. Нажми "+" → "New repository"
4. Имя: kvizlik
5. Выбери Public
6. Нажми "Create repository"
7. Нажми "uploading an existing file"
8. Загрузи ВСЕ файлы проекта (архив распакуй)

⚠️ ВАЖНО: Файл .gitignore уже настроен и скроет:
- .env (там будут секретные токены)
- node_modules
- .next

ВАРИАНТ Б — Через Termux (если установлен):

1. Установи Termux из F-Droid
2. В Termux:
   pkg install git
   cd /sdcard/Download/kvizlik
   git init
   git add .
   git commit -m "КВИЗЛИК v1.0"
   git remote add origin https://github.com/ТВОЙ_НИК/kvizlik.git
   git push -u origin main

=============================================
ШАГ 3: ПОДКЛЮЧИ VERCEL (ХОСТИНГ)
=============================================

1. Открой https://vercel.com в браузере телефона
2. Нажми "Sign Up" → "Continue with GitHub"
3. Дай доступ к твоим репозиториям
4. Нажми "Add New..." → "Project"
5. Выбери репозиторий "kvizlik"
6. Настройки проекта:
   - Framework Preset: Next.js
   - Root Directory: ./ (оставь как есть)
   - Build Command: оставь пустым
   - Output Directory: оставь пустым
7. В разделе "Environment Variables" добавь:

   Имя: BOT_TOKEN
   Значение: (вставь токен от BotFather)

   Имя: WEBAPP_URL  
   Значение: https://kvizlik.vercel.app
   (замени на свой реальный URL, который Vercel покажет после деплоя)

   Имя: DATABASE_URL
   Значение: file:./db/custom.db

8. Нажми "Deploy"
9. Подожди 2-3 минуты пока соберётся
10. Vercel покажет URL вида: https://kvizlik-xxx.vercel.app

🎉 Твой сайт уже работает! Проверь — открой этот URL в браузере.

=============================================
ШАГ 4: ПОДКЛЮЧИ MINI APP К БОТУ
=============================================

Теперь надо сказать Telegram боту, где твой сайт:

1. Открой в браузере телефона ссылку (замени ТОКЕН и URL):
   https://api.telegram.org/botТОКЕН/setMenuButton
   
   НО ЛУЧШЕ так — открой в браузере:
   https://api.telegram.org/bot7123456789:AAHxxx.../setChatMenuButton
   
   Это не сработает напрямую через URL, поэтому:

ПРОСТОЙ СПОСОБ — через @BotFather:

1. Открой @BotFather в Telegram
2. Отправь: /mybots
3. Выбери своего бота
4. Нажми "Bot Settings" → "Menu Button"
5. Вставь URL твоего сайта: https://kvizlik-xxx.vercel.app
6. Готово!

ЕЩЁ ПРОЩЕ — через команду бота:

Открой в браузере (подставь свои данные):
https://api.telegram.org/botТОКЕН/setMyCommands

Нет, самый простой способ:

1. Открой @BotFather
2. /newapp
3. Выбери своего бота
4. Название: КВИЗЛИК
5. Описание: Квиз-игра с лигами и рейтингами
6. Картинка: загрузи любую (скриншот игры)
7. Web App URL: https://kvizlik-xxx.vercel.app
8. Short name: kvizlik

Готово! Теперь у бота есть кнопка для запуска Mini App!

=============================================
ШАГ 6: НАСТРОЙ БОТА (ОПЦИОНАЛЬНО)
=============================================

Чтобы бот отвечал на команды /start и отправлял кнопку Mini App:

1. В Vercel добавь Environment Variable:
   BOT_TOKEN = (токен от BotFather)
   WEBAPP_URL = https://kvizlik-xxx.vercel.app

2. В репозитории на GitHub файл scripts/bot.ts уже готов

3. Либо используй Vercel Serverless Functions (автоматически)
   — при обращении к /api/bot-webhook бот обработает команду

=============================================
ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
=============================================

❌ "Build Error" на Vercel
→ Проверь что все файлы загружены на GitHub
→ Проверь что package.json на месте

❌ Белый экран при открытии
→ Проверь URL в браузере — он должен быть https://
→ Подожди 1-2 минуты после деплоя

❌ Бот не открывает Mini App
→ Проверь что URL указан правильно в BotFather
→ URL должен начинаться с https://

❌ "Environment variable not found"
→ Зайди в Vercel → Settings → Environment Variables
→ Добавь переменную и сделай Redeploy

❌ Прогресс не сохраняется
→ Это нормально для первой версии — данные хранятся в браузере
→ В продвинутой версии подключим базу данных
